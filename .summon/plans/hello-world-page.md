## Context

The repository currently contains only `README.md` — there is no application scaffold, no
`package.json`, no `src/` directory, and no routes. The plan therefore covers creating the
minimal app shell plus the single Hello World page. Nothing existing needs to be preserved.

## Steps

1. Create `package.json` at the project root: ESM (`"type": "module"`), private, with scripts for
   `dev`, `build` (typecheck + vite build), and `preview`. Dependencies: `react`, `react-dom`,
   `@tanstack/react-router`. Dev dependencies: `vite`, `@vitejs/plugin-react`, `typescript`,
   `@types/react`, `@types/react-dom`, `tailwindcss`, `@tailwindcss/vite`,
   `@tanstack/router-plugin`. No other packages.
   Outcome: `npm install` succeeds with no extra dependencies.

2. Create `vite.config.ts` registering, in order, the TanStack Router plugin
   (`@tanstack/router-plugin/vite` in code-splitting/react mode, routes dir `src/routes`,
   generated tree `src/routeTree.gen.ts`), the React plugin, and the Tailwind v4 Vite plugin.
   Add a resolve alias mapping `@` to the `src` directory.
   Outcome: dev server starts, `@/` imports resolve, routes auto-generate.

3. Create `tsconfig.json` (and `tsconfig.node.json` if needed for the Vite config): strict mode,
   `moduleResolution: "bundler"`, `jsx: "react-jsx"`, and `paths` mapping `@/*` to `src/*`.
   Outcome: typecheck passes and editor resolves the alias.

4. Create `index.html` at the project root with a `<div id="root">`, a module script tag pointing
   at `/src/main.tsx`, `lang="en"`, and a page title of "Hello World".
   Outcome: Vite has an entry HTML document.

5. Create `src/styles/global.css` whose first line is exactly `@import "tailwindcss";` and nothing
   else beyond optional base tweaks below that line.
   Outcome: Tailwind v4 utilities are available app-wide.

6. Create `src/main.tsx`: import `@/styles/global.css` once, create the router from the generated
   `routeTree.gen`, register the router type, and render `<RouterProvider>` into `#root` inside
   `React.StrictMode`.
   Outcome: app boots and routing is active.

7. Create `src/routes/__root.tsx` as the app shell: a root route exporting a component that renders
   a full-height wrapper (`min-h-screen`) with a subtle background (e.g. a light neutral base with
   a soft gradient) and antialiased text, containing `<Outlet />`. No nav bar needed.
   Outcome: every page inherits the background and layout container.

8. Create `src/routes/index.tsx` — this is the page that serves the Hello World content and is
   reached at `http://localhost:5173/` (the root URL `/`). Content: a centered flex column that
   fills the viewport height, containing an `<h1>` reading "Hello World" with large, bold, tight
   tracking typography and a balanced responsive size (e.g. scaling up at the `sm`/`md`
   breakpoints), plus a short muted subtitle line below it such as "Your app is up and running."
   Add generous vertical spacing between heading and subtitle, horizontal padding for small
   screens, and a max-width on the text block so it reads well. Optionally a thin divider or small
   uppercase tracking-wide label above the heading for polish. No state, no props, no data
   fetching.
   Outcome: the `/` URL renders the styled Hello World page.

9. Create `.gitignore` covering `node_modules`, `dist`, and local env files. Leave
   `src/routeTree.gen.ts` generated by the plugin and never hand-edit it.
   Outcome: build artefacts stay out of version control.

## Verification

1. Run `npm install` then `npm run dev`; the dev server starts without errors.
2. Open `http://localhost:5173/` — the root URL renders the page from `src/routes/index.tsx`.
3. On screen: a full-height page with a subtle light background, a large bold centered
   "Hello World" heading, and a smaller muted subtitle directly beneath it, vertically and
   horizontally centered in the viewport.
4. Resize the window — text stays centered, keeps side padding on narrow screens, and the heading
   scales down gracefully without overflow.
5. `npm run build` completes with no TypeScript errors.
